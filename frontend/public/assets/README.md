# Earth hero texture

`earth-blue-marble.jpg` is the January global base map from NASA's Blue Marble: Next Generation collection (5400 × 2700 pixels, 8 km/pixel).

Source: [NASA Earth Observatory — Blue Marble: Next Generation, Base Map](https://science.nasa.gov/earth/earth-observatory/blue-marble-next-generation/base-map/)

The image is bundled locally so the landing-page globe does not need an image connection at runtime.
